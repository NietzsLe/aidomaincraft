## Tiếng Việt

Domain UI — dùng item nào CHO UI thì đọc `using-*.md` tương ứng (phần riêng UI + link về gốc). Chi tiết gốc sống trong `items/*/README.md`; index này chỉ điều hướng + định vị.

### Bảng điều hướng: việc → item(s)

Việc landing mẫu có 2 chính: cần taste có sẵn nhanh → Skillry; cần system pass gates → Hallmark. Tiêu chí phân biệt ở ma trận dưới. Việc rebuild site sống: cần giống hệt URL (có quyền) → cloner; cần system mới → Hallmark. Việc audit tokens/drift: cần đo thật + gate CI → dembrandt; cần system mới → Hallmark. Việc review code UI có sẵn: cần 1 pass checklist nhanh ra `file:line` → web-interface-guidelines; findings thuộc về system (tokens/shape/hero) → Hallmark sửa. Việc polish/review/iterate giữ system: cần sửa tới nơi + mắt thấy + detector CI → impeccable chính; findings thuộc system → Hallmark hỗ trợ; chỉ cần list lỗi nhanh → guidelines hỗ trợ. Việc build mới cần taste nhanh: 1 session offline không gates → frontend-design chính; cần gates → Hallmark; cần detector/Live → impeccable. Việc build/audit đúng hệ MD3: cần tokens + audit scoring → material-3 chính; cần taste tự do → frontend-design; cần gates merge → Hallmark.

### Workflow phối hợp mẫu
Hallmark dựng page + system → React Bits lắp 1 background/text effect → chạy lại sweep (`sloplint --render`) + review lạnh. Output Skillry-web lấy về muốn đạt chuẩn thì sweep lại bằng Hallmark; Linux dùng paste-prompt/ZIP thay vì CLI login. Rebuild site sống có quyền → clone bằng ai-website-cloner-template (route map + compare + check xanh), rồi sweep phần custom mới bằng Hallmark. Audit site sống có quyền → extract tokens bằng dembrandt (`--save-output`/`--dtcg`, crawl khi cần), gate drift bằng `--compare` trong CI, sweep tokens thành system bằng Hallmark khi cần chuẩn. Review code UI có sẵn → soi bằng web-interface-guidelines (fetch `command.md` tươi, findings `file:line`), findings nào thuộc về system thì sửa bằng Hallmark. Polish/review UI có sẵn → baseline `npx impeccable detect` → 1 lệnh `/impeccable` mỗi pass → Live/generate compare trực quan → chạy lại detector (before/after JSON) → findings thuộc system thì sửa bằng Hallmark. Taste nhanh 1 session → frontend-design (plan tokens + mirror test + self-critique screenshot); cần gates thì Hallmark sweep; cần detector thì impeccable. Build/audit đúng hệ MD3 → material-3 (tokens/components + theme seed + audit 10 hạng mục); web Expressive thiếu thì custom tay.

Sample landing has 2 primaries: packaged taste fast → Skillry; gated system → Hallmark. See matrix below. Live-site rebuild: exact URL match (with rights) → cloner; new system → Hallmark. Token/drift audit: real measurement + CI gate → dembrandt; new system → Hallmark. Existing-UI review: fast checklist `file:line` pass → web-interface-guidelines; system-level findings → Hallmark fixes. Keep-system polish/review/iterate: fix in place + visual proof + detector CI → impeccable primary; system-level findings → Hallmark supports; fast list only → guidelines supports. Fast taste builds: one offline gateless session → frontend-design primary; gates → Hallmark; detector/Live → impeccable. ### Sample combined workflow
Hallmark builds the page + system → React Bits installs 1 effect → re-run sweep + cold review. Skillry-web outputs that need a standard get re-swept with Hallmark; on Linux use paste-prompt/ZIP. Permitted live-site rebuild → clone with ai-website-cloner-template (route map + comparisons + green check), then sweep new custom parts with Hallmark. Permitted live-site audit → extract tokens with dembrandt (`--save-output`/`--dtcg`, crawl when needed), gate drift with `--compare` in CI, sweep tokens into a system with Hallmark when a standard is needed. Existing UI code review → audit with web-interface-guidelines (fresh `command.md` fetch, `file:line` findings), fix system-level findings with Hallmark. Keep-system polish/review → baseline `detect`, one `/impeccable` command per pass, Live/generate visual compare, re-run detector (before/after JSON), fix system-level findings with Hallmark. Fast one-session taste → frontend-design (token plan + mirror test + self-critique screenshots); gates → Hallmark sweep; detector → impeccable. Spec-faithful MD3 build/audit → material-3 (tokens/components + seed themes + 10-category audit); full web Expressive missing → hand custom.
