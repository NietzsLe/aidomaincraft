# Nguồn tham khảo tin cậy — wireframe-docs

> `ref:` trong tree chỉ nên trỏ các nguồn dưới đây. Ngoài danh sách:
> designer quote ok tường minh mới được dùng (ghi vào CHANGELOG khi duyệt).
> Nguồn sự thật nội bộ luôn là `convention/` của item này.

## Motion / animation

- easings.net (đường cong + preview trực tiếp)
- cubic-bezier.com (tự chỉnh bezier, copy giá trị)
- Material Design — motion (material.io/design/motion)
- Apple Human Interface Guidelines — motion

## Component / pattern

- shadcn/ui docs (ui.shadcn.com/docs/components — nguồn pin từ vựng)
- Radix Primitives docs (radix-ui.com/primitives — hành vi gốc shadcn dựa vào)
- WAI-ARIA Authoring Practices (w3.org/WAI/ARIA/apg — pattern bàn phím chuẩn)

## Accessibility / đánh giá thiết kế

- web-interface-guidelines, item `../` trong repo (checklist 130 rules;
  `command.md` là nguồn khi soi UI code thật)
- MDN ARIA Roles (đối chiếu mapping role)
- WCAG 2.2 Understanding (w3.org/WAI/WCAG21/Understanding)

## Quy tắc thăng cấp

- Custom `ref:` được dùng ≥3 lần ở các bản khác nhau → đề xuất đưa vào
  `animations.md` thành tên gọi chung (ghi quyết định vào CHANGELOG).
- Nguồn mới muốn vào danh sách tin cậy → designer duyệt + ghi lý do 1 dòng.
